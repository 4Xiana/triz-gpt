TRIZ 是什么

TRIZ（俄语 «Теория решения изобретательских задач» 的拉丁缩写，意为「发明问题解决理论」） 由苏联发明家、专利审查员根里奇·阿奇舒勒（Genrich Altshuller）于 1946 年起创立。 他和团队分析了数十万件高水平发明专利，发现技术发明并非偶然的灵感， 而是遵循反复出现的规律——工程系统总是在「解决一个矛盾」中进化。 TRIZ 就是把这些规律提炼成的一套可操作的创新方法论。

核心思想：创新有规律可循

  • 技术系统进化法则：系统总是朝着提高「理想性」的方向发展——功能越来越强，代价与副作用越来越小。
  • 矛盾是发明的起点：当改善系统的一个属性会导致另一个属性恶化时，就构成了技术矛盾；真正的发明不是折中妥协，而是彻底消除矛盾。
  • 解法可以跨领域复用：不同行业的发明背后反复出现同一批解题策略，这些策略被归纳为 40 个「发明原则」。
  • 从具体到抽象、再回到具体：把具体问题抽象成标准参数矛盾，用标准工具找到抽象解法，再类比迁移成你的具体方案。

TRIZ 的几件「标准工具」

⚖️ 理想性公式 理想性 = 有用功能 ÷（成本 + 有害副作用）。本系统的评审专家即按收益、成本、副作用三个维度十分制打分。

用 TRIZ 解题的标准流程

  1. 具体问题：描述你面临的工程/设计困境（如「起落架既要坚固又要轻」）。
  2. 抽象参数：识别希望改善与随之恶化的工程参数（运动物体重量 ⇄ 应力/压力）。
  3. 查矩阵：在矛盾矩阵中查出推荐的发明原则。
  4. 选原则：理解原则背后的解题思路，矩阵空单元时可通览 40 原则自行推断。
  5. 类比迁移：把抽象原则转译为针对你问题的具体方案。
  6. 评估迭代：按理想性评估方案，持续优化直到满意。
